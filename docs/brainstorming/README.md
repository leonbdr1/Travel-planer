# Brainstorming-Archiv

Hier liegen Brainstormings, deren Inhalt sich lohnt aufzuheben: Erkenntnisse, begründet verworfene Ideen, Abwägungen. Die Regeln stehen in `CLAUDE.md` §Brainstorm-Modus.

- Das **Ergebnis** eines Brainstormings (beschlossene Änderungen, fehlende Funktionen) steht immer in `FORTSCHRITT.md` §„Offene Punkte aus Brainstormings“. Dieses Archiv ist nur die Begründung dazu.
- Brainstormings ohne neue Erkenntnisse bleiben im Chat und brauchen hier keine Datei.
- Alles auf Funktionsebene: was der Nutzer sieht und tun kann. Keine Dateinamen, kein Code, keine technischen Lösungen.

## Dateiname

`YYYY-MM-DD-<thema>.md`, z. B. `2026-09-30-startseite-suchleiste.md`.

## Vorlage

```markdown
# <Thema> (<Datum>)

## Ausgangslage
Was stört heute, was soll der Nutzer können?

## Erkenntnisse
Was beim Durchdenken herausgekommen ist.

## Beschlossen
Was geändert werden soll. Jeder Punkt steht auch als `B<n>` in `FORTSCHRITT.md`.

## Verworfen
- <Idee> – Grund: <warum nicht>

## Offene Fragen
Was Ben noch entscheiden muss.
```
